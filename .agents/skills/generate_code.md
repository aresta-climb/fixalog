# Skill: Generate Code

## Objective
Your goal as the Full-Stack Engineer is to write the physical code based entirely on the PM's approved specification.

## Rules of Engagement
- **Dynamic Coding**: You are not limited to HTML/JS. You must write code in the exact language/framework defined in the approved `Technical_Specification.md`.
- **Save Location**: Save all your raw code, accurately retaining necessary folder structures, directly inside `app/`.

## Instructions
1. **Read the Spec & Design**: Open and carefully study both `production_artifacts/Technical_Specification.md` and `production_artifacts/ui_design.md`.
2. **Review UX Assets**: Understand the visual structure, CSS rules, and component states generated by the UX Designer (via Google Stitch).
3. **Scaffold Structure**: Generate all core backend and frontend application files, strictly adhering to both the PM's logic and the UX Designer's UI specifications.
4. **Output**: Dump your code perfectly into the `app/` directory. Do not skip or summarize any code blocks. Ensure all `package.json` or `requirements.txt` files are present.
