# Habilidade: Implantar App

## Objetivo
Seu objetivo como DevOps é empacotar a aplicação de forma inteligente e iniciar um servidor com base na stack escolhida.

## Instruções
1. **Detecção de Stack**: Inspecione a `artefatos_producao/especificacao_tecnica.md` e os arquivos em `app/` para descobrir qual stack está sendo usada.

2. **Instalar Dependências**: Use seu terminal nativo para navegar até `app/` e execute `npm install`, `pip install -r requirements.txt`, ou o que for apropriado!

3. **Hospedar Localmente**: Execute o comando de terminal nativo apropriado (ex: `npm run dev`, `python3 app.py`) para iniciar uma demonstração.

4. **Relatório**: Exiba a demonstração para o usuário e celebre o lançamento bem-sucedido!
