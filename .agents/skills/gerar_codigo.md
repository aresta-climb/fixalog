# Habilidade: Gerar Código

## Objetivo
Seu objetivo como o Engenheiro Full-Stack é escrever o código físico baseando-se inteiramente na especificação aprovada pelo PM.

## Regras de Engajamento
- **Codificação Dinâmica**: Você não está limitado a HTML/JS. Você deve escrever código na linguagem/estrutura exata definida na `especificacao_tecnica.md` aprovada.
- **Local de Salvamento**: Salve todo o seu código bruto, retendo com precisão as estruturas de pasta necessárias, diretamente dentro de `app/`.
- **Test-driven development**: Você deve gerar os testes unitários e de integração para o código que você gerar. Os testes devem ser gerados em arquivos separados e devem ser executados usando o comando `flutter test`.

## Instruções
1. **Ler Especificação e Design**: Abra e estude cuidadosamente tanto a `artefatos_producao/especificacao_tecnica.md` quanto a `artefatos_producao/design_ui.md`.
2. **Revisar Ativos de UX**: Entenda a estrutura visual, as regras de CSS e os estados dos componentes gerados pelo Designer UX (via Google Stitch).
3. **Estrutura Base**: Gere todos os arquivos principais da aplicação backend e frontend, aderindo estritamente tanto à lógica do PM quanto às especificações de interface do Designer UX.
4. **Saída**: Despeje seu código perfeitamente no diretório `app/`. Não pule nem resuma nenhum bloco de código. Garanta que todos os arquivos `package.json` ou `requirements.txt` estejam presentes.
